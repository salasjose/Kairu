# **App Name**: EcoQuest Explorers

## Core Features:

- Interactive Educational Route: A visually engaging route with station buttons that unlock sequentially as challenges are completed.
- Biodiversity Challenge: A timed challenge where users identify flora and fauna species by matching images with names. Limited attempts provided.
- Habitat Creation Submission: Users upload photos documenting the construction and installation of wildlife feeders/watering stations.
- Sustainability Tracker: A seven-day photo journal where users document their sustainable practices daily.
- Content Upload and Sharing: Users create and share videos (via URL upload from platforms like YouTube, Instagram, TikTok) demonstrating participation in clean-up drives or waste separation practices.
- Gamified Knowledge Check: Interactive quiz with random questions to test user knowledge of water conservation and other learned topics.
- Adaptive Crossword Puzzle: AI-powered tool that generates a unique crossword puzzle (10x10) using vocabulary related to previous topics.

## Style Guidelines:

- Primary color: Forest green (#3F704F) evoking nature and growth.
- Background color: Very light green (#F0FAF3), providing a soft, natural backdrop.
- Accent color: Earthy brown (#A0522D), used sparingly for highlighting key actions.
- Font pairing: 'Alegreya' for headings and 'PT Sans' for body, creating a blend of elegance and readability. Alegreya is a serif font and PT Sans is a sans-serif.
- Use icons that represent each challenge.
- Intuitive navigation with clear visual cues for unlocked and locked stations.
- Subtle transitions and celebratory animations upon completion of tasks.
